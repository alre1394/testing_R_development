# Palmer penguins dataset

Measurements for penguins observed in the Palmer Archipelago,
Antarctica.

## Usage

``` r
data(penguins)
```

## Format

A data frame with 344 rows and 8 columns:

- species:

  Penguin species: Adelie, Chinstrap, or Gentoo.

- island:

  Island where the penguin was observed.

- bill_len:

  Bill length in millimetres.

- bill_dep:

  Bill depth in millimetres.

- flipper_len:

  Flipper length in millimetres.

- body_mass:

  Body mass in grams.

- sex:

  Penguin sex.

- year:

  Year of observation.

## Source

Horst AM, Hill AP, Gorman KB (2020). Palmer Archipelago penguin data.
Available at <https://allisonhorst.github.io/palmerpenguins/>.
